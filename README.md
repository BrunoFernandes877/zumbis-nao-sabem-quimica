# Zumbis Não Sabem Química
### 20 dias para transformar um porão em bunker com a Química

Jogo digital educativo de sobrevivência, para o 9º ano do Ensino Fundamental e o Ensino Médio. O estudante está preso em um porão durante um apocalipse zumbi, com um computador e a ÍRIS, uma assistente de inteligência artificial. A energia vai acabar em 20 dias. Até lá, ele precisa usar a Química para transformar o porão em um bunker autossustentável: purificar água, conservar alimentos, cultivar uma horta, gerar energia com pilhas caseiras e fazer sabão.

**▶ Jogar:** abra o link do GitHub Pages deste repositório (Settings → Pages).

## Origem

Este jogo é um remix do REA **"Sobrevivência Humana: Ciência para Viver em Um Mundo Hostil"**, de **Gilciara Paixão Gonçalves**, publicado no repositório Aquarela em 23/01/2026. O REA original é baseado no livro *Conhecimentos Químicos que Você Precisa para Sobreviver ao Apocalipse Zumbi* (UFPR, 2021).

## Como usar

O jogo é um único arquivo (`index.html`) e roda direto no navegador, sem instalação. O progresso fica salvo no navegador do próprio aparelho. O Painel do Professor, dentro do jogo, gera códigos de turma e reúne os resultados enviados pelos estudantes.

## Aviso

O jogo foi desenvolvido com o auxílio de uma inteligência artificial generativa e pode conter bugs e erros conceituais. Recomenda-se que o professor o teste antes de aplicá-lo em sala. Os procedimentos simulados no jogo, como a produção de sabão com soda cáustica, não substituem as orientações de segurança dos experimentos reais. Relatos de erros e sugestões são bem-vindos na aba *Issues* deste repositório.
